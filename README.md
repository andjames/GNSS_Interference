A quick little scraper for pulling the NASA Earthdata for GPS quality at stations impacted by "accidental" noise from Russian satellite during a select set of days and times.

NOTE:
Needs a .netrc file with your EarthData username & password in the ./ location on your computer. Otherwise should pull, process, and produce a CSV and chart of the related data.

A preview of the dataset can be found on my data viz tool at https://rawgraphs-app-six.vercel.app/.

Demo called "Russian Interference with GPS"
